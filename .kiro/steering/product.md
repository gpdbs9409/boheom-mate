# 제품 (Product)

## 무엇을 만드는가
`boheom-mate`: 실손의료보험 약관(KB 등)을 근거로 질문에 답하는 RAG 상담 서비스.
보험사가 "보험설계사와 고객이 모두 쓰기 편한 약관 질의응답"을 목표로 의뢰한 제품이라고 가정한다.

## 두 사용자, 한 제품
- **보험설계사/상담 담당**: 정확한 조항 근거와 숫자가 필요하다. 근거 원문·조항 위치를 항상 보여 준다.
- **일반 고객**: 약관 용어를 모른다. 쉬운 말, 결론 먼저, 금액은 굵게.
- 한 답변이 두 사용자를 모두 만족해야 한다: 쉬운 설명 + 검증 가능한 근거를 함께 제시한다.

## 최우선 원칙 (순서대로)
1. **틀리지 않기 > 많이 답하기.** 금융 도메인이라 틀린 답은 금전 손해·민원으로 이어진다.
   근거가 없으면 지어내지 말고 "약관에서 확인할 수 없음"으로 답한다.
2. **금액은 코드가 계산한다.** LLM은 계산에 쓸 숫자만 모으고, 계산은 `calculator.py`가 한다.
3. **한계를 숨기지 않는다.** 면책·연간 한도·기수령·세대 차이 때문에 실제와 다를 수 있음을 항상 안내하고,
   "실제 지급은 보험사 심사로 확정"임을 명시한다.

## 핵심 기능 (범위)
1. 약관 넣기(PDF → 조항 분할 → 임베딩 → Chroma)
2. 질문 → 관련 조항 검색(하이브리드) → 근거 밝힌 답변
3. 근거 조항 원문 표시 / 없으면 확인 불가
4. 이어지는 상담 + 보험금 계산기(참고용)

범위 밖(사용자 요청 전 구현 금지): 로그인, 알림, 공유, 관리자 화면, 화면 PDF 업로드, 여러 약관 비교 등.

## 상세 맥락
프로젝트 전체 사실·결정·현황은 루트 `common.md`가 단일 진실 소스다. 이 steering과 충돌하면 `common.md`를 따른다.
