# 업무 절차: 새 실손 약관 확인·반영 (수동)

정리일: 2026-10-19 · 주기: 주 1회 · 대상: 보험사 실손의료보험 약관

## 1) 시작

구글에서 보험사 공시실을 검색해서 들어간다.

## 2) 순서

1. 구글에서 보험사 공시실을 검색해 들어간다.
2. 실손 약관 목록을 보고 새 약관이 있는지 확인한다.
3. 새 약관이 있으면 PDF를 내려받는다.
4. 받은 PDF를 `data/` 폴더에 넣는다.
5. 앱의 "약관 넣기" 탭에서 그 PDF를 골라 조항이 잘린 결과를 확인한다.
6. 결과가 괜찮으면 저장한다(`chroma_db/`에 저장됨).
7. `chroma_db/`를 rsync로 EC2에 올린다.

## 3) 판단이 들어가는 곳

- 5단계: 조항이 잘린 결과를 보고 **이상하면 저장하지 않는다.**

## 4) 걸리는 시간

보험사 한 곳 기준 약 30분.

## 5) 끝나는 곳 (남는 결과물)

- `data/`: 내려받은 약관 PDF
- `chroma_db/`: 저장된 약관 조항
- EC2 서버: rsync로 올라간 `chroma_db/` (사이트에서 상담 가능)

## 자동화 후 (2026-10-19~)

1. 월요일 9시쯤 Slack에 `[주간 약관 확인]` 요약과 새 약관별 메시지가 온다(서버가 공시실 확인·PDF 받기·조항 점검까지 한다).
2. 약관 메시지의 점검 결과(정상 / 확인 필요)를 읽는다.
3. **판단:** 넣을 약관에만 "승인" 답글을 단다. 넣지 않을 약관은 그냥 둔다.
4. 5분 안에 "반영 완료" 답글이 달리고 사이트에서 상담할 수 있다.
- 자동 확인이 안 되는 보험사는 PDF를 서버 `data/inbox/`에 `보험사__상품 이름__판.pdf`로 넣는다.
- 자세한 내용: `docs/slack-setup.md`
